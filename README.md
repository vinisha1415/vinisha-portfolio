# Vinisha Vittal Bangera — QA Portfolio

A personal portfolio website built with HTML and CSS.

## About
This site showcases my QA engineering background across Healthcare and BFSI domains,
including mainframe testing expertise and modern automation skills.

## Tech Stack
- HTML5
- CSS3 (vanilla, no frameworks)
- Google Fonts

## Features
- Responsive design
- Sticky navigation
- Skills, Experience, Projects, and Contact sections

## Run Locally
Just open `index.html` in any browser. No build step needed.
